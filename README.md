# ROSTOV REMONT

Многостраничный демонстрационный сайт компании по ремонту квартир в Ростове-на-Дону. Светлая тема, тёмно-зелёная типографика и сдержанный латунный акцент. Заголовки — Tenor Sans, основной текст — Golos Text. Шрифты с лицензиями хранятся в `fonts/`, внешние сервисы для их загрузки не нужны.

**Демо:** https://trip-prog.github.io/rostov-remont/

## Навигация

На компьютере разделы видны в шапке. На узких экранах кнопка **«Открыть меню»** открывает панель навигации. Она закрывается по фону, по `Esc` и по крестику; фокус остаётся внутри открытой панели.

Ссылки на все услуги продублированы в подвале обычным HTML — это карта сайта для поисковика и запасная навигация, если скрипт не загрузился.

## Видео с объектов

Три вертикальных ролика в `media/` запускаются стандартными кнопками плеера. При запуске следующего предыдущий останавливается. При скрытии вкладки воспроизведение приостанавливается. Обложки `project-*-cover.jpg` — кадры из тех же роликов; `kitchen-detail.jpg` и `ceiling-detail.jpg` используются на страницах услуг. Видео отображаются целиком, без обрезки.

## Фотографии

Все 27 оригиналов из папки `работы/` сохранены. По умолчанию видны все направления, начиная с плиточной отделки. Фильтр оставляет выбранное направление; якорь в адресе позволяет открыть его напрямую. Без JavaScript ссылки работают как обычная навигация по разделам.

В фотографиях услуг и компании также используются только предоставленные работы и кадры этих видео. Стоковые интерьеры, вымышленные отзывы, история и неподтверждённые показатели удалены.

Фотографии открываются внутри страницы. Стрелки и клавиши влево/вправо листают снимки выбранного направления. Закрытие — крестик, фон или `Esc`, с возвратом фокуса на исходный снимок. Обложка использует тот же просмотр.

## Юридический блок (152-ФЗ)

Форма заявки не отправляется без отметки о согласии на обработку персональных данных: кнопка выглядит заблокированной, а при попытке отправки подсвечивает нужный чекбокс. Форма демонстрационная и не отправляет данные; поля времени согласия и редакции документов сохранены в макете. Номер можно ввести с +7, с 8 или десятью цифрами, без маски, мешающей редактированию.

Cookie-баннер показывается один раз, выбор хранится 12 месяцев в `localStorage`. Аналитика подключается только внутри `loadAnalytics()` — то есть после явного «Принять», до этого не грузится ничего.

Страницы в `legal/` самодостаточны: у них своя минимальная вёрстка с запасными значениями цветов, поэтому они читаются, даже если стили сайта не подгрузились.

## Архитектура

Сайт **генерируется** из единого источника данных, а не правится в 21 файле руками. Исключение — папка `legal/`: юридические документы правятся вручную и в сборке не участвуют.

```
tools/
  site.data.mjs    — все данные: услуги, проекты, видео, отзывы, контакты, меню
  layout.mjs       — каркас: <head>, шапка, выезжающее меню, подвал
  blocks.mjs       — блоки: hero, карточки, прайс-таблица, FAQ, форма
  build.mjs        — сборка страниц + проверка данных
  check-links.mjs  — проверка всех внутренних ссылок и якорей
```

Добавить услугу — дописать объект в `services` внутри `site.data.mjs` и пересобрать: страница, пункт меню, карточка в каталоге, строка в прайсе и ссылка в подвале появятся сами.

```bash
node tools/build.mjs
```

Проверить целостность ссылок:

```bash
node tools/check-links.mjs
```

Результат сборки — обычные `.html` в репозитории. GitHub Pages отдаёт их как есть, без сборки на стороне сервера.

## Стек

Чистые HTML + CSS + JS, без зависимостей и бандлера. Адаптив и поддержка `prefers-reduced-motion`. Общий скрипт `js/main.js` запускает блоки только на страницах с соответствующей разметкой.

Проверка поведения галереи без установки зависимостей: `node tools/check-lightbox.mjs`. Проверяются фильтры, прямые якоря, все 27 фотографий, переключение альбома и возврат фокуса.

## Запуск локально

Открыть `index.html` в браузере или поднять статический сервер:

```bash
python -m http.server 4173
```

> Демонстрационный проект. Форма заявки не отправляет данные на сервер, карта и реквизиты условные.
